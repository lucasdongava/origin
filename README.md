# Parity

Compare two DNS zones for a domain migration: see what is missing at the destination and what can be left behind.

- Paste a BIND zone file or a table copied from a DNS panel, or read a screenshot (OCR runs in the browser).
- Say what has to keep working (website, email, subdomains...) and copy the records to add and remove.
- Nothing is stored or sent anywhere. Everything runs in the browser.

Static site: open `index.html`. No build step.
